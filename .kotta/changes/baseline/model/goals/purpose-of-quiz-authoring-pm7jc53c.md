# Purpose of quiz-authoring

## Outcome

Lets the AI turn course material into questions and quizzes, the largest gain over core web services, which cannot create questions or quizzes at all. Targets the Moodle 5.x question bank model.

## Context

Quizzes are the biggest gain over core web services and the strongest demo moment.

## Baseline and target

Baseline: core web services cannot create a question or a quiz. Target: questions imported, a quiz built hidden, and opened only when the teacher wants.
