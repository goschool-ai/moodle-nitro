# Moodle site administrator

## Role

The site administrator of an institution's or faculty's Moodle. Not always the same person as the web server operator.

## Goals

Offer Nitro to the teachers who should have it, under the institution's rules, and be able to narrow or stop it at any time.

## Responsibilities

Installs and upgrades the plugin, adds the web server discovery rule, switches Nitro on or off, grants `local/nitro:use`, chooses the allowed tools, redirect URIs and registration options, registers clients by hand where needed, and reads the audit log.
